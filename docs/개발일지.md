## 결정과 이유

- **자료를 7개 자리로 나눴습니다** — 원자재 당월·전월, 제품 당월·전월, 입고 이력, 출고·사용 이력, 단가표. 기획서 3장의 자료 목록 그대로입니다. 필수는 원자재 또는 제품의 당월 재고 하나이고, 나머지는 올린 만큼 계산이 켜집니다(없으면 화면에 무엇을 못 계산했는지 안내).
- **컬럼 짝짓기를 먼저 두었습니다.** 실제 컬럼명을 아직 받지 못했기 때문입니다(기획서 10장 2번). 흔한 이름(품번·자재코드·현재고·재고수량 등)으로 자동 짐작하고, 사용자가 고친 짝은 자료 종류별로 저장해 다음 달 파일에 그대로 씁니다. ERP 내려받기 파일에 흔한 제목 줄을 위해 머리행 위치를 바꿀 수 있고, 여러 시트 파일은 시트를 고릅니다.
- **한글 CSV 인코딩을 직접 가립니다.** 엑셀에서 저장한 한글 CSV 는 EUC-KR 인 경우가 많아, UTF-8 로 읽어 보고 깨지면 EUC-KR 로 다시 읽습니다. CSV 는 값 자동 변환을 끄고 읽어 품번 앞자리 0 이 사라지지 않게 했습니다.
- **Aging 은 두 기준을 모두 계산하고, 표시·구간·적정성 판정은 최근 출고일 기준입니다.** 제출 원문이 원자재·제품 두 곳에서 반복해 적은 기준입니다. 품목별 표와 엑셀에는 입고일 기준·출고일 기준 일수를 나란히 둡니다.
- **적정·과잉·불용은 Aging 일수로 나눕니다**(기획서 5장). 과잉·불용 기준 일수와 Aging 구간 경계는 모두 설정값이고, 처음 들어 있는 90·180·365 와 180·365 는 예시 값이라고 화면에 적었습니다.
- **단가는 적용일이 있으면 기준일 이전 가장 최근 값을 씁니다.** 당월 금액은 당월 기준일, 전월 금액은 전월 기준일 단가입니다. 단가 변동이 금액 증감에 섞이는 것이 실제 재고금액 보고와 같다고 보았습니다(가정).
- **재고 파일에 금액 컬럼이 있으면 짝지을 수 있게** 했고, 단가표와 파일 금액 중 무엇을 우선할지 설정에서 고릅니다. 단가도 파일 금액도 없는 품목은 금액을 비워 두고 「금액 미산정」 건수로 표시합니다(0 으로 채우지 않음).
- **관리대상 후보 규칙**: 금액 증가 상위 N건(원자재·제품 각각), 과잉, 불용(장기 미출고), 저회전(회전율 기준을 넣었을 때만). 한 품목에 사유가 여럿이면 한 줄에 모아 적습니다. 관리대상 시트에는 담당자가 채울 「원인」「개선방안」 빈 칸을 두었습니다. 원인·개선방안을 도구가 지어 쓰지는 않습니다(AI 초안은 3단계).
- **엑셀은 한 파일, 시트 8개**로 내려받습니다. 마지막 「기준」 시트에 계산에 쓴 기준일·구간·판정 기준과 예시 데이터 여부를 남겨, 나중에 숫자가 어떤 기준으로 나왔는지 알 수 있게 했습니다.
- **스크립트를 ES module 이 아닌 일반 스크립트로** 불러옵니다. `index.html` 을 파일로 열면(file://) 브라우저가 module 스크립트를 막아 화면이 통째로 비기 때문입니다.

## 가정

- 입고일 기준 Aging 은 **최근 입고일**부터 셉니다. 선입선출 잔량 기준(가장 오래 남은 입고분)으로 셀지는 확인이 필요합니다(기획서 10장 4·5번).
- 출고 이력이 없는 품목은 기본값으로 **최근 입고일로 대신 계산**하고 「입고일 대체」라고 표시합니다. 설정에서 「판정 보류」로 바꿀 수 있습니다(기획서 10장 5번).
- 회전율 = 당월 출고수량 ÷ ((전월 수량 + 당월 수량) ÷ 2). 당월 출고수량은 전월 기준일 다음 날부터 당월 기준일까지의 출고 합계입니다. 저회전 판정 기준은 확인 전까지 비워 두는 것이 기본입니다(기획서 10장 8번).
- 입고·출고 이력은 원자재·제품 공통 한 파일씩으로 보고, 품번(제품코드)으로 연결합니다. 원자재와 제품의 코드가 겹치지 않는다고 보았습니다.
- 같은 품번이 재고 파일에 여러 줄(창고·로트별)이면 수량과 파일 금액을 더합니다.
- 품번은 앞뒤 공백만 지우고 그대로 비교합니다. 엑셀에서 숫자로 저장된 품번과 글자로 저장된 품번(앞자리 0)은 서로 다르게 보일 수 있어, 단가 미매칭 화면에 확인 안내를 적었습니다.
- 증감률은 전월 값이 0 이면 계산하지 않고 「신규」로 표시합니다.

## 수강생 실제 자료가 있어야 하는 것

1. 월말 재고 파일(원자재·제품), 입고·출고 이력, 단가표의 실제 컬럼명과 익명화 샘플 1~2개월분 — 짝짓기 확인, 기존 엑셀 분석 결과와 숫자 대조
2. 원자재 대분류 체계
3. Aging 구간 경계와 적정·과잉·불용 기준 일수(회사 기준)
4. 입고일 기준 Aging 을 최근 입고일로 셀지, 선입선출 잔량 기준으로 셀지
5. 출고 이력이 없는 품목의 처리 방법
6. 단가 기준(이동평균·표준단가·최근 입고단가)과 적용일 유무
7. 관리대상 선정 기준(증가 상위 몇 건, 금액 기준), 장기 미판매·저회전 판정 기준
8. 현재 결과 보고 양식 — 엑셀 시트 구성을 맞추기 위함
