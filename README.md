## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-05/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

사용 순서는 다음과 같습니다.

1. **자료** — 원자재·제품의 당월·전월 재고, 입고 이력, 출고·사용 이력, 단가표·기준정보를 자리마다 올립니다(엑셀·CSV). 인천·대구처럼 공장별 파일은 같은 자리에 하나씩 더 올리고 파일마다 공장을 지정합니다(파일 이름에 「본사」「인천」「대구」가 있으면 자동). 한 통합문서에 7월·8월 시트가 있으면 당월·전월 자리에 같은 파일을 올리면 달 이름으로 시트를 골라 둡니다. 머리행(맨 위 제목 줄)과 컬럼 짝도 자동으로 짐작하고, 한 번 고친 짝은 다음 달 파일에 그대로 씁니다. 한글 CSV(EUC-KR·UTF-8)를 모두 읽습니다.
2. **기준 설정** — 당월 기준일, Aging 구간(개월), 과잉·불용 기준(개월), 원자재 대분류 묶음표(HSG=하우징류 …), 관리대상 기준을 넣습니다. 처음 들어 있는 숫자는 예시 값입니다.
3. **원자재 분석 · 제품 분석 · 증감 원인 · 관리대상 · 단가 미매칭** 화면을 확인합니다. 화면 위 **공장 보기(합계·인천·대구)** 로 공장별로 봅니다. 오른쪽 위 **「분석 결과 엑셀 내려받기」** 로 시트 12개짜리 엑셀을 받습니다.

처음 열면 자료가 비어 있습니다. 「자료」 화면의 **「예시 데이터 불러오기」** 를 누르면 시연용 가상 데이터가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

- 올린 파일은 외부로 보내지 않습니다. 짝지은 결과와 기준은 **이 브라우저(localStorage)에만** 저장됩니다.
- 예시 파일: `samples/예시데이터_8월재고분석(본사).xlsx`·`예시데이터_8월재고분석현황(대구).xlsx`·`예시데이터_기준정보관리.xlsx`(실데이터의 열 구조만 흉내 낸 가상 값) + 가상 입출고 이력 CSV 2개. 회사 실데이터는 이 리포에 넣지 않습니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 파일 올리기·컬럼 짝짓기 | 완료 | 엑셀(xlsx·xls)·CSV 업로드, 시트 선택, 머리행 위치 지정, 필드별 컬럼 지정·자동 짐작, 짝 저장(다음 달 자동 적용), 문제 행(코드 빈칸·숫자 아님) 집계 |
| 원자재 대분류별 집계 | 완료 | 대분류별 품목 수·재고수량·재고금액, 합계 행 |
| 전월 대비 증감 | 완료 | 수량·금액 증감과 증감률, 신규·소멸 품목 표시, 같은 품번 여러 줄은 합산 |
| 단가매칭 | 완료 | 품번으로 단가 결합, 적용일이 있으면 기준일 이전 가장 최근 단가(당월·전월 각각), 매칭 실패 목록 화면·시트 |
| Aging 분석 | 완료 | **개월 단위**(09-29). 입고일·최근 출고일 기준 경과 개월 모두 계산(달력 월 차이, 말일 규칙), 표시는 최근 출고일 → 재고 파일 경과 개월(재고잔량분석) → 입고일 순, 예전 일 단위 설정 자동 변환 |
| 제품 고객사별 증감 | 완료 | 고객사별 재고수량·금액 증감과 증감률 |
| 재고 적정성 구분 | 완료 | Aging(표시 기준) 경과 개월로 적정·과잉·불용, 기준 개월은 설정값(불용 12개월 초과 = 회사 총괄표 불용과 같음) |
| 관리대상 후보 선정 | 완료 | 금액 증가 상위 N건, 과잉·불용(장기 미출고), 저회전(회전율 기준을 넣었을 때). 장기 미판매·저회전 기준 확정은 2단계 |
| 엑셀 내려받기 | 완료 | 시트 12개(공장별 요약, 원자재 대분류별·증감원인·증감기여·품목별, 제품 고객사별·증감원인·품목별, Aging·적정성, 관리대상, 단가 미매칭, 기준). 증감원인 시트에 원인 메모·AI 해설 |
| 증감 원인 보조 | 완료(09-29) | 대분류별 금액 증감 = 입고 + 출고·사용 + 조정·기타 + 단가 변동 + 신규 + 소멸 + 금액 미산정, 기여 상위 N 품목, 입고·출고 전월→당월, 원인 메모. 발주량은 자료 없음 |
| AI 원인·조치 초안 | 완료(반자동, 09-29) | 대분류마다 프롬프트 생성(품번·품명 가림 기본) → ChatGPT 등에 붙여 넣고 답을 다시 붙여 넣기 |
| 공장 구분(인천·대구) | 완료(09-29) | 공장별 파일 여러 개, 파일 이름·공장 칸으로 공장 지정, 중국 행 제외, 합계·인천·대구 보기 |
| 월별 추이 누적 | 다음 단계 | 3단계 |
| 월간 보고 자동 발송 | 다음 단계 | Make, 3단계 |
