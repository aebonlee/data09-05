## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-05/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

사용 순서는 다음과 같습니다.

1. **자료** — 원자재·제품의 당월·전월 재고, 입고 이력, 출고·사용 이력, 단가표를 자리마다 올립니다(엑셀·CSV). 컬럼 이름이 달라도 「어느 컬럼이 품번·수량인지」 한 번 짝지어 두면 다음 달 같은 형식 파일은 자동으로 짝지어집니다. 맨 위에 제목 줄이 있으면 머리행 위치를 바꿉니다. 한글 CSV(EUC-KR·UTF-8)를 모두 읽습니다.
2. **기준 설정** — 당월 기준일, Aging 구간, 과잉·불용 기준 일수, 관리대상 기준(증가 상위 건수, 저회전 회전율)을 넣습니다. 처음 들어 있는 숫자는 예시 값입니다.
3. **원자재 분석 · 제품 분석 · 관리대상 · 단가 미매칭** 화면을 확인하고, 오른쪽 위 **「분석 결과 엑셀 내려받기」** 로 시트 8개짜리 엑셀을 받습니다.

처음 열면 자료가 비어 있습니다. 「자료」 화면의 **「예시 데이터 불러오기」** 를 누르면 시연용 가상 데이터가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

- 올린 파일은 외부로 보내지 않습니다. 짝지은 결과와 기준은 **이 브라우저(localStorage)에만** 저장됩니다.
- 예시 파일: `samples/예시데이터_*.csv`(자리별 7개)와 `samples/예시데이터_재고분석_자료모음.xlsx`(시트 7개). 모두 가상 데이터입니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 파일 올리기·컬럼 짝짓기 | 완료 | 엑셀(xlsx·xls)·CSV 업로드, 시트 선택, 머리행 위치 지정, 필드별 컬럼 지정·자동 짐작, 짝 저장(다음 달 자동 적용), 문제 행(코드 빈칸·숫자 아님) 집계 |
| 원자재 대분류별 집계 | 완료 | 대분류별 품목 수·재고수량·재고금액, 합계 행 |
| 전월 대비 증감 | 완료 | 수량·금액 증감과 증감률, 신규·소멸 품목 표시, 같은 품번 여러 줄은 합산 |
| 단가매칭 | 완료 | 품번으로 단가 결합, 적용일이 있으면 기준일 이전 가장 최근 단가(당월·전월 각각), 매칭 실패 목록 화면·시트 |
| Aging 분석 | 완료 | 입고일 기준·최근 출고일 기준 모두 계산, 표시·구간·판정은 최근 출고일 기준, 구간 경계 입력식, 출고 이력 없는 품목 처리 방식 선택 |
| 제품 고객사별 증감 | 완료 | 고객사별 재고수량·금액 증감과 증감률 |
| 재고 적정성 구분 | 완료 | Aging(표시 기준) 일수로 적정·과잉·불용, 기준 일수는 설정값 |
| 관리대상 후보 선정 | 완료 | 금액 증가 상위 N건, 과잉·불용(장기 미출고), 저회전(회전율 기준을 넣었을 때). 장기 미판매·저회전 기준 확정은 2단계 |
| 엑셀 내려받기 | 완료 | 시트 8개(원자재 대분류별·품목별, 제품 고객사별·품목별, Aging·적정성, 관리대상, 단가 미매칭, 기준). 관리대상 시트에 원인·개선방안 기입 칸 |
| 증감 원인 보조 | 다음 단계 | 입고량·사용량·발주량 전월 비교 화면(2단계) |
| AI 원인·조치 초안 | 다음 단계 | 익명화 후 3단계 |
| 월별 추이 누적 | 다음 단계 | 3단계 |
| 월간 보고 자동 발송 | 다음 단계 | Make, 3단계 |
